# 使用指南

## 配置与工作流

首次启动进入「必填配置」。先启动本机 ComfyUI，填写地址并导入 API 格式 JSON。也可以读取 ComfyUI 运行/等待队列或最近执行记录；尚未提交的浏览器画布不能通过服务端 API 读取。

「工作流参数」中的小型图片上传框读取 ComfyUI 原图的执行图元数据，导入后刷新节点表与生成参数。支持 PNG、WebP、JPEG，推荐未转存的原始 PNG。仅有编辑器布局而没有执行图、元数据无效或缺失时显示原因，保留原配置。

标准单 KSampler 工作流可自动绑定。字符串节点、字符串拼接和布尔文本/潜空间分支在已识别的类型范围内支持。多 sampler、其他条件节点和复杂自定义节点需要高级 JSON 明确绑定；没有安装的模型和节点不能由此工具自动安装。

读取参数后，点击左侧节点编号，编辑区逐行显示可编辑参数。可跨节点连续修改后统一保存；重新读取会清除未保存输入。种子、提示词、批次数由生图表单控制。绕过和布尔分支快速记录选择，提交新任务时应用；已有任务保留提交时快照。

节点表下的「添加 LoRA 节点」选择本机已安装文件、MODEL/CLIP 接入位置和强度，支持 LoraLoader 及已安装的 LoraLoaderModelOnly。先保存未提交的参数修改，再添加节点。循环连接、不可用文件或越界数值会被拒绝。

云端连接可填写 API 根地址或 Chat Completions 端点、提示词模型及视觉模型。模型能力、端点内容范围需要确认，严格 JSON Schema 可按端点能力选择。保存连接发送小型测试请求，可能收费；密钥默认保留在服务内存，可选系统凭据库。目录同步失败时可以手工填写模型。

## 提示词生图与图片反推

填写正负提示词、张数、输出文件夹和生成参数。关闭质量审查时不调用云端，生成成功即保存；开启时按原图进行云端评审。直接提示词按用户原文使用，不经过自动主题设计。

正向提示词上方的紧凑「图片反推」入口只执行工作流中的独立反推分支，成功后回填正向提示词。没有独立分支时禁用普通反推。

入口下勾选「传图识别工作流」后改为读取原图元数据，导入对应工作流并填入正负提示词、尺寸、步数、CFG、种子、采样器与调度器。此方式不需要反推节点，也不调用云端。取消勾选恢复普通反推。上传会显示读取中与成功/失败说明；运行中的任务需要暂停并等待当前处理完成才能替换配置。

旁边的同尺寸「输入图片识别」入口只填入提示词，不替换工作流。优先读取原始 PNG、WebP 或 JPEG 的 ComfyUI 执行图、文本提示词及常见 parameters 元数据；没有可读取的提示词时，使用已配置的视觉模型反推。说明会区分原始元数据与模型推测；模型反推采用当前提示词页确认的内容范围，默认限额为 0.10 USD 和 5000 token，可展开「模型反推限额」修改。此操作进入顺序队列，不提交生图；失败不会清空已有正负提示词。

## 创作讨论

「人工干预」右侧的「创作讨论」用于与提示词模型讨论画面需求。新讨论默认沿用已保存 API 的内容范围，无需重复配置连接；也可在讨论设置显式选择范围和独立预算。选择的范围与 API 不匹配时，界面说明应如何调整。发送后沿用本讨论范围与预算，显示已用费用、待结算费用及 token。模型没有图片、文件、工作流或生图执行权限。

每段讨论保留多轮上下文与本机记录。新建讨论清空当前窗口；选择「讨论记录」后点击「载入讨论」可继续旧讨论。无有效连接、预算不足或无效模型回复会显示原因并保留输入，避免不明白是否已发送。重复提交同一次消息不会再次调用模型。

模型整理出完整提示词后，「可应用的提示词」会列出对应回复，可预览正负提示词并点击「一键应用到提示词生图」。应用仅填入文本和跳转，已有参数保留，仍需手动点击开始生图。尚在澄清需求的回复不能应用。

图片详情下的「转到创作讨论」位于「转到提示词生图」右侧、尺寸相同。点击后在新讨论的输入框准备该图本轮实际正负提示词；可以补充修改要求后发送，不会自动调用模型或生图。

## 自动生图

参考来源选择上传图片或本机文件夹，隐藏来源不参与处理。默认抽样 15 张，滑条范围 1–50，数字输入可更大；数量变化尽量复用已有抽样与打标，「换一批」重新抽样。打标使用已确认的云端视觉模型，计入费用。

填写共同要求、主题组数和每组张数。每行主题对应一组：不足时模型补足，超出时抽选，留空则随机设计；选定主题保存到本任务。参考图用于学习提示词写法、权重和细节表达，各组独立安排人物、姿势、镜头与场景。

未指定控制角色、LoRA 触发词或固定外观时，自动规划要求各组更换人物外观锚点，如发色、瞳色、发型和长度；仅换种子、衣服或场景不算更换角色外观。各组有不同的外观设计起点，并只读取其他组已规划的简短外观特征来避免重复，不复制其他组场景。模型按本组风格适配：写实使用自然外观，风格化可使用更鲜明的配色，黑白风格通过发型轮廓、长度和明暗区分。组内迭代也可修改模型自行设计的外观；明确指定的角色、触发词和控制特征优先保留，仅调整未约束的部分。已通过的提示词仍可复用，直接提示词与按原图重画保留原有规则。此要求约束提示词规划，实际成图差异仍取决于模型与工作流。

控制词每行包括组号、tags、权重与删除按钮，同高并排，权重/删除较窄。组号填「全部」或用中英文逗号指定组，如 1，3,5；tags 同样用逗号分隔。同行共用权重，留空由模型设计，填写 0.1–3 后锁定；本地保证最终提示词保留对应组的控制词。同组重复 tag 或越界组号会提示错误。

「控制角色」是非必填项，可以逐行添加，每行指定组号与角色名/作品/补充特征。组号用中英文逗号分隔；留空或填「全部」应用到所有组，最多 30 行。同组可指定多个不同角色，提示词模型只将该组角色的基本外观写入正向提示词；没有联网搜索，不明确的角色可补充描述。角色分组用于首次规划、迭代和评分；按图或按组重画沿用原图所在组的角色。旧方案的单个角色仍可载入为全部组。LoRA 触发词由用户填写并加入正向提示词。这些设置随任务、常用方案和上次配置保存，跨组不继承上一组的无关人物或场景。

选择输出目录、综合分数线、每组最大轮数及预算等限额，再开始。点击后立即给出提交反馈、已等待时间和实际准备阶段；加入顺序队列后显示当前阶段。ComfyUI 提供真实步数时才显示百分比，其他阶段用等待动画。

本轮已评审结果的五官、手部、结构等通用问题用于后续组规划与迭代；不把其他组的人物、场景或控制词复制过去。共享方向可从本轮记录恢复，不额外调用总结模型。

云端提示词规划同时要求构图连贯、主体数量与动作明确、空间层次和肢体归属清楚，避免冲突视角、多余或缺失部位、可见五官模糊和不合理融合。复杂动作表达不清时优先简化，尊重用户的裁切、遮挡与景深；具体安排写入正向，对应缺陷写入负向。首次规划、自动迭代和人工重画使用相同要求。

## 评审与交付

综合合格线默认 42，可自定义。解剖、结构与手部的明显畸形数值线为 42；安全、重复与必需评分完整性仍参与判断。模型置信度和单独的改进建议不会额外提高综合门槛。中文界面要求后续评审依据与建议使用中文；生成 tags 和 JSON 字段保持原样。旧评分原始记录保持不变，已有对应显示译文时优先显示译文。

后续评审逐项检查多余肢体、部位缺失、人物融合、连接断裂、身体重复与内容范围，并说明具体位置。明确异常独立拦截，综合高分也不能抵消；遮挡、画外裁切和风格化简化不直接当成缺失。无法评估的脸保留“不可判定”，不伪造 0 分畸形。内容范围允许的成人内容本身不作为违规。详情会展示逐项结果和判定原因，避免把结构或范围拦截误解成低于综合及格线。最终评审传图最长边上限提高至 1536（仍受模型能力限制）；可能增加图片输入 token，沿用任务预算。视觉模型仍可能误判，可人工重画或重新评审。

自动任务由程序完成质量判定和交付，不设置逐张人工接受/拒绝关卡。遇到结构异常、低于 42 的解剖/结构/手部分数、判断矛盾、结构疑点、必需评分缺项或内容范围尚未明确时，会用模型再次检查原图。复核要求独立判断可见连接、部位归属、具体异常和实际内容范围，不传初次分数或指控，给出最终评审；普通遮挡、画外裁切、风格化简化和审美偏好不直接扣成畸形。每张图最多保存一次有效复核结果，沿用原任务预算和限额；正常图达到综合门槛后自动保存，确认异常或仍缺失必需评分时继续迭代。明确异常、低于 42 的结构数值、范围违规、重复与综合门槛仍参与最终判断，不改写原始分数。正常检查配有轻微绘画建议时无需额外复核。已明确处于允许范围的内容，不因成人内容匹配分不足而转人工确认；内容匹配与实际违规分别判断。

旧版本留下的待审、候选图和评分缺项，在恢复自动任务后自动处理：已有完整且合格的评分可直接保存，其余疑点用原图模型复核，保留已有图片和进度。已结束为「部分完成」且仍有待处理原图的自动审查任务，恢复时继续原任务，先处理已有图，沿用原预算与限额。复核遇到格式或连接错误仍会说明原因并暂停；恢复后复用初次评分与原图，成功复核已经保存时不重复调用。达到预算、token、轮数等限额时交付已有合格图并报告不足，不再等待人工批准候选图。已停止或暂停的历史任务不会自行恢复付费调用。

原图复查不传旧分数和旧指控，以减少沿用第一次误判；初次评审仍完整留在本机记录。抬起、弯曲、伸出或交叉的手臂先核对肩、上臂、肘、前臂、腕、手的连接，再评分，不能把被子、衣袖或头发的线条当成肢体连接。即使数值高、检查表全为正常，只要同时报告手臂/手部疑点却没有连接依据，也会触发原图复查。握拳或抓物时不要求五指、指甲和所有指缝全部可见；风格化线条简化不能单独认定为畸形。构图单独看主体焦点、画面平衡、取景和空间关系，华丽光照或精细背景不能代替结构与构图判断。

开启初筛时，缩略图的复核建议不会跳过原图最终评审；按既有任务预算继续判断原图。自动任务的人工接受/拒绝按钮隐藏；重新评审、按图重画或删除仍可作为可选补救，无需每张图操作。受保护图片复查失败时保留原图，并自动排除出合格交付，不转人工待审。历史人工模式兼容原有选择操作。纯审美建议和普通遮挡不直接当作人体缺失。以上校验不能保证云端视觉识别始终准确，历史评审保持原始记录。

基础模糊与 pHash 检查默认运行。CLIP、美学和 NSFW 学习指标默认未配置，不造分数；需要安装 metrics 可选依赖及相应的本地权重。模型不自动下载。

    python -m pip install -e ".[metrics]"

可选权重目录通过 SUPERVISOR_CLIP_MODEL、SUPERVISOR_AESTHETIC_MODEL、SUPERVISOR_NSFW_MODEL 环境变量配置；CLIP 使用 CLIPModel/AutoProcessor，美学使用 0–10 单输出回归，NSFW 使用对应分类标签。

界面任务必填输出目录，默认平铺写入图片，文件名标注任务与组。合格图逐张保存；关闭审查时逐张直接保存。开始前可选 ZIP，也可在结果页打包。评分、提示词和分析记录留在应用本机数据目录。缺图、目录不可写或 ZIP 写入失败会说明原因，不用为了重新交付而重新生图。

## 图片总览与详情

图库沿用缩略图预览，最多载入最近 50 张；默认包含此前任务及历轮图片，可取消历史开关只看当前任务。等待新任务时旧图仍显示。每张图标注自己的来源、组、轮次与评分状态；进度与预算对应当前所选任务。

点击图片直接显示该图的评分、依据、改进建议、正负提示词和实际生成参数。放大按钮在页面内显示大图，四周留白、背景模糊；Esc 返回详情，关闭恢复总览，后台刷新不会重新打开已关闭详情。

图片下可选产出 1–50 张、是否生成后审查，再点击「批量产出」。复用所选图自己的提示词、参数、模型和执行工作流，逐张更换种子，沿用输出设置，新任务独立计费并顺序排队。开启审查时张数指合格图目标，仍受轮数、预算等限额影响；重复点击同一请求不创建重复任务。

「转到提示词生图」自动填入所选图正负提示词。删除键左侧的环形箭头表示人工不满意后「重画」：模型根据该图原提示词、控制要求与评审修订提示词，再生成与评审，原图保留。只想更换种子时使用批量产出。

红色删除图标直接删除应用管理的原图、缩略图和对应交付副本，原始参考文件与 ComfyUI 输出保留。永久删除后的小预览不能恢复高清图。历史人工任务仍按其原隔离/清理设置处理。

## 队列、停止与恢复

参考图打标、图片反推和生图在同一持久工作队列中顺序执行。任务拥有各自配置快照，修改新工作流不会替换已排队任务。排队与暂停时间不消耗运行时长，预算按任务独立计算。

- **结束本轮工作**：取消等待任务，已提交的当前输出收集处理后结束；保留已有图片，新任务可继续提交。
- **执行剩余队列**：运行仍排队的工作，不重启已取消任务。
- **当前输出后停止**：处理完当前输出再暂停当前任务。
- **恢复当前任务**：沿用所选暂停任务的进度，继续未完成处理。
- **再生成一轮**：运行中或已结束任务均可创建独立新轮，复用设置、已有参考分析和已生成的各组提示词；尚未规划的组在执行时规划。新轮预算与运行时长独立计数。

结果页展开「各组进度」可查看实际执行与等待队列中的生图任务，已经结束的历史任务不进入这份列表；选中历史任务也不会把它重新加入队列。当前执行组下方显示随页面强调色变化的标线，任务编号区分同组号的不同轮次。运行中与尚未运行的组右侧只显示小号删除键；已运行结束的组只显示环形重绘键。重绘取该组最后一轮可用图片的提示词和工作流，沿用原组目标张数，创建独立任务加入队列，原图保留。按钮立即显示处理反馈，同一请求重复点击不会重复排队。删除取消该组后续工作，已有图片与提示词保留。尚未提交的图片不再生成，已提交的当前图片先收回，随后停止该组；其余组继续。取消全部组的任务退出队列，取消组不再计入完成目标。

云端评审可兼容问题项中的 `location`、依据摘要、翻译附注和 `advice`：位置写入评审记录，依据文字与建议分别保留在对应说明中，问题项的建议合并到顶层改进建议。仅接受受长度限制的说明文字，不覆盖评分、异常标记或问题严重程度。云端异常标记若误写成字符串，仅将明确的 `true`、`false`、`null` 转为对应布尔值或未知值，不推测描述性文字；本地异常判定保持严格校验。评分缺失、越界、无效结构检查和冲突字段仍会暂停任务。页面会分别说明额外字段、空说明、长度超限或不可解析 JSON，格式问题与网络连接失败分开提示。格式失败后可「恢复当前任务」评审已有图片，不必重新生图。

附加 `overall` 仅检查取值有效，不替代本地按单项计算的综合分。没有异常时缺省检查说明可为空；有异常时只能复用模型已给出的对应人体问题依据或检查附注，无法取得依据仍暂停。自定义校验错误记录受限的具体原因，后续格式修复请求和页面提示均可指出冲突、说明类型或长度问题，不保存模型原始回复。

可调整当前任务的每组目标、轮数和分数线，再点击「应用到当前任务」。预算不足、评审回复无效、模型拒答、网络或不确定提交会显示具体原因和下一步，不静默丢图或盲目重复提交。
